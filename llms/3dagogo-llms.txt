# AstroPrint (3DaGoGo, Inc.)

> AstroPrint is a cloud platform for consumer and professional 3D printing, built by 3DaGoGo, Inc. (San Diego, CA). It provides browser-based slicing, AI model generation, remote WiFi printer control, live print monitoring, print-queue management, and analytics — serving 260,000+ users across 130+ countries. AstroPrint exposes a REST API (OAuth 2.0) so third parties can extend the platform.

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public surface. No provider-published /llms.txt exists (probe returned 404).

## API
- [AstroPrint Cloud API](https://developer.astroprint.com/): REST API at https://api.astroprint.com/v2, protected by OAuth 2.0 (client_credentials and authorization_code grants). Token endpoint: https://api.astroprint.com/v2/token. Example resource: /v2/printers.
- [3D Print API](https://astroprint.github.io/3d-print-api-sample/): Client-side JavaScript library (astroprint.import.js) to inject STL/ZIP designs into AstroPrint user accounts.
- [Developer Portal](https://developer.astroprint.com/): Register apps, obtain client_id/client_secret, configure OAuth.
